# For You — scrapbook webpage

A small GitHub Pages webpage inspired by the supplied scrapbook-style reference video.

## Files

- `index.html` — scenes and images
- `style.css` — scrapbook / hand-drawn styling
- `script.js` — timing, audio, and editable lyric placeholders
- `assets/photos/` — your 12 photos
- `assets/audio/song.mp3` — reference audio

## Edit the lyrics

Open `script.js` and replace only the placeholder text in `lyrics` with lyrics you are permitted to use. Adjust the `time` values if you want different timing.

## Edit the final message

In `index.html`, change `TYPE YOUR MESSAGE HERE` near the bottom.

## GitHub Pages

Upload the files while keeping the folder structure intact, then enable GitHub Pages from the repository's Settings → Pages.
